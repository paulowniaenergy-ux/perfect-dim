# Perfect Dim

Локальний демонстраційний сайт агенції нерухомості для продажу будинків біля Луцька.

## Запуск

```bash
npm install
npm run dev
```

Після запуску відкрийте `http://localhost:3000`.

## Основні маршрути

- `/` — головна сторінка
- `/catalog` — каталог із фільтрами
- `/property/sosnovyi-dim-strumivka` — приклад сторінки об’єкта
- `/about` — про агенцію
- `/contacts` — контакти та форма заявки
- `/admin` — локальна адмінка

## Адмінка

Адмінка працює без зовнішніх сервісів: зміни й завантажені фото зберігаються лише у `localStorage` поточного браузера. Вона підтримує додавання, редагування, видалення, зміну ціни, фото та статусів «Доступний», «Заброньований», «Проданий». Продані об’єкти залишаються в каталозі.

Кнопка «Відновити демодані» повертає початкові 20 об’єктів.

## Заміна логотипа

Текстовий плейсхолдер винесено в `components/brand.tsx`. Після отримання логотипа замініть позначку `PD` та текст `Perfect Dim` на зображення з `public/logo.svg` або інший потрібний файл.

## Примітка

Телефон, адреса, месенджери та email у демоверсії є плейсхолдерами. Форми не передають дані назовні.
